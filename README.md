# 🏠 AI Architect — 평면도 자동 생성기

대지 정보와 방 구성을 입력하면 AI가 최적의 평면도를 자동으로 생성합니다.

## 기능
- 📍 대지 정보 입력 (주소, 면적, 용도지역, 건폐율/용적률)
- 🏠 방 구성 — 각 방 이름 + 치수 직접 입력
- 🧭 8방위 향 선택
- 📐 SVG 평면도 자동 생성
- 📥 SVG 다운로드

## 기술 스택
- **Frontend**: HTML5, CSS3, Vanilla JS
- **Backend**: Hono + TypeScript
- **Rendering**: SVG (룰 기반 배치 엔진)
